# Clash Website

Simple, clean website for Clash - based directly on the README.

## Features

- **Minimal Design**: Clean, documentation-style layout
- **README-based**: Content directly from the main README.md
- **Demo GIFs**: All demos included
- **Quick Start**: Installation and usage instructions
- **Responsive**: Works on all devices

## Development

```bash
# Install dependencies
npm install

# Start development server (port 5177)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

Push to GitHub and deploy with Vercel:

```bash
vercel
```
